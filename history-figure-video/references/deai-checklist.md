# 去AI味清单（历史人物版）

改编自 novel-book skill 去AI味清单，适配历史人物短视频旁白场景。

## 操作流程

按顺序执行以下 6 步，每步完成后检查，全部 0 违规才输出。

---

## 第1步：黑名单硬替换

**必须**将以下词汇从旁白文本中彻底清除：

| 原词 | 替换方案 |
|------|----------|
| 然而 | 删除，或用"但"替代 |
| 不禁 | 删除，直接描述动作 |
| 心中暗想 | 删除，直接写心理活动 |
| 宛如宿命 | 删除，重新组织 |
| 命运的齿轮 | 删除，改为具体动作或事件 |
| 她终于明白了 | 删除，改为具体动作或物件 |
| 说不清的情绪 | 删除，改为身体反应或具体行为 |
| 复杂的情绪 | 删除，改为一个具体情绪+一个身体反应 |
| 空气仿佛凝固了 | 删除，改为具体感官细节 |
| 不由自主地 | 删除，直接写动作 |
| 难以言喻的 | 删除，改为可描述的具体感受 |
| 心头一震 | 删除，改为身体反应 |
| 一股暖流涌上心头 | 删除，改为具体动作或触感 |
| 嘴角微微上扬 | 删除，改为具体表情动作 |
| 眼神中闪过一丝 | 删除，改为具体眼神描述 |
| 不知为何 | 删除，直接写事实 |
| 莫名地 | 删除，直接写事实 |
| 仿佛有什么东西在心底碎裂 | 删除，改为具体动作 |
| 那双深邃的眼眸 | 删除，改为具体描述 |
| 他沉默了许久，终于开口 | 删除，直接写对话 |
| 她垂下眼帘，掩去了眼中的情绪 | 删除，改为具体动作 |
| 历史的长河 | 删除，改为具体年代或事件 |
| 时光荏苒 | 删除，直接写过了多少年 |
| 岁月如梭 | 删除，直接写过了多少年 |
| 沧海桑田 | 删除，改为具体变化 |
| 历史会记住 | 删除，改为具体事实 |
| 千古流传 | 删除，改为具体记载 |

---

## 第2步：否定句转肯定句

扫描全文，用否定词描述状态的（没有、不是、并未、无法、不能），重写为肯定客观描述。

**错误**：他不是没有注意到她的目光。
**正确**：他注意到了。但她装作没看见。

**错误**：她无法控制自己的情绪。
**正确**：她攥紧衣角，指甲掐进掌心。

**错误**：这座城并不安宁。
**正确**：这座城夜里总有人失踪。

---

## 第3步：剥离心理锚点

删除"他知道"、"他感觉到"、"他意识到"、"她明白"、"他想起了"。
直接写出他知道的、感觉到的、意识到的事实。

**错误**：他知道她在撒谎。
**正确**：她的眼神飘向门口。撒谎。

**错误**：他意识到局面已经失控。
**正确**：门外的脚步声越来越近。他握住剑柄。

**错误**：她想起小时候母亲说过的话。
**正确**：母亲的话突然浮上来——"别碰那扇门。"

---

## 第4步：移时比喻审查

历史人物旁白大量使用移时手法（现代词汇翻译古代事物），需审查移时比喻是否**误导历史认知**。

**检查项**：
- 移时比喻是否歪曲了历史事实的本质？（如把"流放"说成"出差"会淡化刑罚性质）
- 移时比喻是否让听众误以为古代制度=现代制度？
- 关键史实（法律、刑罚、等级制度）是否用了过于轻佻的比喻？

**错误**：上官婉儿被没入掖庭，相当于进了宫里的底层打工人。
**正确**：上官婉儿被没入掖庭——说白了，就是从官家小姐变成了宫里的奴婢。不是打工，是没得选。

**错误**：宰相就是CEO。
**正确**：宰相——用现在的话说，相当于CEO，但权力比CEO大得多，能决定谁生谁死。

**原则**：移时可以用，但必须**加限定**，让听众知道"这只是类比，不是等同"。

---

## 第5步：形容词压缩

扫描形容词堆叠。一个名词最多配 1 个形容词。超过的，删。

**错误**：他那双深邃而忧郁的眼睛里闪烁着复杂而微妙的光芒。
**正确**：他眼里有光。很暗。

**错误**：冰冷的、锋利的、泛着寒光的剑刃
**正确**：泛寒的剑刃

**检查项**：
- 名词前是否有 2 个以上形容词？
- 形容词是否在说同一件事？（"冰冷刺骨的寒风"→"寒风"）
- 是否可以用动词替代形容词？（"美丽的天空"→"天光铺开"）

---

## 第6步：逐句自检

输出前，**必须**逐句核对：

| 检查项 | 标准 |
|--------|------|
| 黑名单词汇 | 0 出现 |
| 否定句 | 每个否定句都有不可替代的理由（对话语气、双重否定修辞除外） |
| 心理锚点 | 0 出现 |
| 移时比喻 | 无误导历史认知的轻佻比喻 |
| 形容词堆叠 | 每个名词最多1个形容词 |
| AI腔排比 | 无"没有…没有…也没有…"式排比 |
| 感悟式结尾 | 章末无"他终于明白了""这一刻她懂了" |
| 出处标注 | 野史/墓志铭内容是否标注了来源和可靠性 |

全部通过后输出，进入文案质检环节。
