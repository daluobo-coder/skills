# 抖音历史人物赛道风格规范

## 频道品牌

- **频道名**:平章说(出自《尚书》"平章百姓",意为评理论定)
- **开篇slogan**:"平章说,{本集核心反转/焦点}"
- **结尾slogan**:"读史明事理,平章说"

## 开篇钩子

"平章说"三个字就是品牌,每集必用。逗号后直接抛核心矛盾/反转,不绕弯,不寒暄。前3秒必须抓住注意力,不用"大家好"开头。

**示例**:
- 上官婉儿E01:"平章说,她爷爷被武则天杀了,她却成了武则天最信任的人"
- 杨贵妃:"平章说,马嵬坡那天,她到底死没死?"

## 单集内部钩子

- 每集只讲一个核心冲突,讲透
- 中间段落用"可事情没那么简单""但墓志铭上写的完全不是这么回事"等转折推进
- 结尾留悬念驱动追更

## 结尾互动引导

- **每集结尾**(非最后一集):留悬念钩子 + "读史明事理,平章说,下集见"
- **系列最后一集**:总结 + 互动 + "读史明事理,平章说"

## 视频时长

- **每集3-5分钟**,一个人物3-5集
- 总时长10-25分钟,接近"中视频"区间
- 每集narration总字数600-1200字(按3字/秒估算)
- 每集拆5-8个小节,每节80-200字

## 发布标题格式

- **定稿格式**：`姓名(序号)：标题内容`
- 序号用中文数字：一、二、三、四
- 标题总长≤20字，格式部分约8-10字，标题内容8-12字
- 标题内容取自视频章节标题，不用另拟

**示例**:
- 妲己(一)：有苏之女
- 帝辛(二)：宗教改革
- 比干(三)：姜子牙护身符
- 妇好(一)：请缨伐土方
- 伊尹(四)：放逐太甲
- 武丁(三)：征伐鬼方

## 发布简介

- 1-2句话，提炼本集核心冲突/反转/看点
- 风格：悬念+反常识+故事感
- 不用"今天我们来讲"等套话开头

## 话题标签

- **必带**：`#平章说` `#{人物名}` `#商朝`(或对应朝代) `#人文历史`
- 选带（按内容选1-2个）：`#历史真相` `#封神演义` `#考古` `#甲骨文` `#女将军` `#姓氏起源` `#正史vs野史` `#竹书纪年` `#牧野之战` `#殷墟` `#军事史`
- 每集4-6个话题，不要堆太多

## publish.txt 格式

每集目录下放 `publish.txt`，三行格式：
```
标题（第一行）
简介（第二行）
话题（第三行）
```

示例：
```
妲己(一)：有苏之女
有苏氏战败献女求和，"妲己"不过是族姓拼出来的称呼。正史对她只写了一句，后世却加了无数罪状。
#平章说 #妲己 #商朝 #人文历史 #历史真相
```

## HTML视觉风格

| 元素 | 规范 |

| 主色 | #1a0e0a(深褐/历史感) |
| 辅色 | #d4a847(古金) |

**故事页**:左上角章节标题(古金56px)+ 红色短横线

**结尾页**:居中金句 + "读史明事理,平章说"
