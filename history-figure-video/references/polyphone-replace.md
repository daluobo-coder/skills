# 多音字替换策略

TTS对多音字敏感,写文案时**必须主动规避**,用无歧义的同义词替换。

## 替换表

| 多音字 | 替换方案 |
|--------|----------|
| 朝(cháo/zhāo) | 宋朝→宋代,朝代→年代,朝阳→晨光 |
| 行(xíng/háng) | 行走→走路,银行→钱庄,行军→出兵 |
| 长(zhǎng/cháng) | 长大→成年,长官→上司 |
| 重(zhòng/chóng) | 重视→看重,重复→再来,重兵→大军 |
| 乐(yuè/lè) | 音乐→乐曲,快乐→欢喜 |
| 好(hǎo/hào) | 好读书→爱读书,好奇→多问 |
| 将(jiāng/jiàng) | 将来→以后 |
| 为(wéi/wèi) | 因为→因,成为→成了,为人→做人 |
| 和(hé/huò) | 和亲→联姻,和平→太平 |
| 分(fēn/fèn) | 分封→封地,身份→地位 |
| 便(biàn/pián) | 便宜→价低,方便→便利 |
| 还(huán/hái) | 还乡→回乡,还有→另有 |
| 教(jiāo/jiào) | 教书→授课,宗教→佛道 |
| 觉(jué/jiào) | 觉得→感到,睡觉→入睡 |
| 落(luò/là/lào) | 落魄→潦倒,落第→没考中 |
| 差(chā/chà/chāi) | 差点→险些 |
| 种(zhǒng/zhòng) | 种地→务农,种子→种籽 |
| 传(chuán/zhuàn) | 传说→传闻,传记→生平 |
| 调(diào/tiáo) | 调动→调任,调整→调理 |
| 弹(tán/dàn) | 弹琴→抚琴,子弹→弹药 |
| 相(xiāng/xiàng) | 宰相→丞相,相信→信 |
| 发(fā/fà) | 发生→出事,头发→发丝 |
| 当(dāng/dàng) | 当时→那时,当真→真的 |
| 处(chǔ/chù) | 处理→处置,到处→处处 |
| 数(shù/shǔ) | 数次→多次,数字→数目 |
| 量(liàng/liáng) | 大量→大批,测量→丈量 |
| 率(lǜ/shuài) | 概率→可能,率领→带领 |
| 强(qiáng/qiǎng) | 强大→强盛,勉强→硬撑 |
| 塞(sāi/sài/sè) | 塞外→边关,堵塞→堵住 |
| 曾(céng/zēng) | 曾经→曾,曾孙→玄孙 |
| 奇(qí/jī) | 奇怪→古怪,奇数→单数 |
| 少(shǎo/shào) | 少年→年少,多少→几多 |
| 冠(guān/guàn) | 冠军→头名,衣冠→衣帽 |
| 载(zǎi/zài) | 记载→记录,载入→写入 |
| 度(dù/duó) | 制度→规矩,揣度→猜测 |
| 假(jiǎ/jià) | 假如→如果,假期→休假 |
| 参(cān/shēn) | 参加→参与,人参→参 |
| 系(xì/jì) | 关系→关联,系上→绑上 |
| 血(xuè/xiě) | 鲜血→血,流血→出血 |
| 角(jiǎo/jué) | 角落→角落(固定),角色→人物 |
| 没(méi/mò) | 没有→无,淹没→吞没 |
| 似(sì/shì) | 似乎→好像,似的→般 |
| 应(yīng/yìng) | 应该→该,答应→应承 |
| 令(lìng/lǐng) | 命令→下令,令尊→您父 |

## 原则

- 能用无歧义的同义词替换就替换
- 不能替换的用固定搭配
- 文案完成后,必须用pypinyin逐字检查,标记所有多音字并确认替换

## pypinyin检查脚本

```python
from pypinyin import pinyin, Style

POLYPHONE_CHARS = {
    '朝': ['cháo', 'zhāo'], '行': ['xíng', 'háng'],
    '长': ['zhǎng', 'cháng'], '重': ['zhòng', 'chóng'],
    '乐': ['yuè', 'lè'], '好': ['hǎo', 'hào'],
    '将': ['jiāng', 'jiàng'], '为': ['wéi', 'wèi'],
    '和': ['hé', 'huò', 'hè'], '分': ['fēn', 'fèn'],
    '便': ['biàn', 'pián'], '还': ['huán', 'hái'],
    '教': ['jiāo', 'jiào'], '觉': ['jué', 'jiào'],
    '落': ['luò', 'là', 'lào'], '差': ['chā', 'chà', 'chāi'],
    '种': ['zhǒng', 'zhòng'], '传': ['chuán', 'zhuàn'],
    '调': ['diào', 'tiáo'], '弹': ['tán', 'dàn'],
    '相': ['xiāng', 'xiàng'], '发': ['fā', 'fà'],
    '当': ['dāng', 'dàng'], '处': ['chǔ', 'chù'],
    '数': ['shù', 'shǔ'], '量': ['liàng', 'liáng'],
    '率': ['lǜ', 'shuài'], '强': ['qiáng', 'qiǎng'],
    '塞': ['sāi', 'sài', 'sè'], '曾': ['céng', 'zēng'],
    '奇': ['qí', 'jī'], '少': ['shǎo', 'shào'],
    '冠': ['guān', 'guàn'], '载': ['zǎi', 'zài'],
    '度': ['dù', 'duó'], '假': ['jiǎ', 'jià'],
    '参': ['cān', 'shēn'], '系': ['xì', 'jì'],
    '血': ['xuè', 'xiě'], '角': ['jiǎo', 'jué'],
    '没': ['méi', 'mò'], '似': ['sì', 'shì'],
    '应': ['yīng', 'yìng'], '令': ['lìng', 'lǐng'],
}

def check_polyphones(text):
    issues = []
    for i, char in enumerate(text):
        if char in POLYPHONE_CHARS:
            start = max(0, i-3)
            end = min(len(text), i+4)
            context = text[start:end]
            readings = POLYPHONE_CHARS[char]
            issues.append(f"  ⚠️ '{char}' ({context}) 可能读音: {'/'.join(readings)}")
    return issues
```
