# 海洋渐变

深邃、专业、权威。传达深度与精确。

## 基础配色

- **深蓝**: `065A82` — 主背景色 / 标题页背景
- **蓝绿**: `1C7293` — 次强调色，章节标题
- **午夜蓝**: `21295C` — 深强调色，页脚条
- **浅蓝**: `E8F4F8` — 内容页背景
- **白色**: `FFFFFF` — 深色上的文字

## 扩展色板

- **accent**: `028090` — CTA/高亮/编号/装饰圆
- **页脚深**: `0A3D5C` — 页脚条背景
- **正文色**: `1A1A2E` — 近黑标题
- **正文灰**: `333333` — 正文
- **副文字**: `666666` — 弱化文字
- **弱文字**: `888888` — 最弱文字
- **卡片底**: `FFFFFF` — 白色卡片
- **斑马纹**: `F0F7FA` — 表格交替行
- **分隔线**: `D0DDE5` — 细线/边框

## 语义色

| 语义 | 文字色 | 背景色 | 用途 |
|------|--------|--------|------|
| 风险 | `C0392B` | `FDE8E8` | 高风险指标、警告 |
| 关注 | `E67E22` | `FFF3E0` | 需关注项、中性提醒 |
| 健康 | `2E7D32` | `C8E6C9` | 正面指标、健康状态 |

## 深色背景文字色阶

| 元素 | 色值 |
|------|------|
| 主标题 | `FFFFFF` |
| 副标题 | `E0F0F8` |
| 说明文字 | `C0D8E8` |
| 弱化文字 | `8ABCD0` |
| ❌ 避免 | `8FAFC0` (对比不足) |

## 图表配色

```javascript
// 单色柱图
chartColors: ["1C7293"]

// 多色饼图
chartColors: ["21295C", "028090", "1C7293", "A0C8D8"]

// 折线图
chartColors: ["028090"]
```

## 字体搭配

- **标题**: Cambria 粗体
- **正文**: Calibri

## 适用场景

金融分析、研究演示、学术会议、医疗健康、政府报告。
