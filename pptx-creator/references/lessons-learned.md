# 经验库

从实际使用中积累的设计经验和教训。智能体在生成 PPT 前必须读取此文件，避免重复犯错。

---

## PptxGenJS 技术陷阱

### 颜色格式
- **绝不带 `#` 前缀**：PptxGenJS 用 `"1E2761"` 而非 `"#1E2761"`
- **渐变背景的 stops 中颜色也不能带 `#`**：`{ color: "065A82" }` 而非 `{ color: "#065A82" }`
- **母版渐变背景可能报错**：`createColorElement` / `genXmlColorSelection` 错误时，改用纯色背景

### 表格颜色
- **行级 `color` 选项会与单元格级冲突**：不要在 `addTable` 的行选项中设 `color`，统一在单元格级别设置
- **单元格 `fill` 用对象格式**：`fill: { color: "1E2761" }` 而非 `fill: "1E2761"`

### 文本换行
- **连续文本混排极易断裂**：不要在一个 `addText` 中堆叠"标题+数据+说明"的连续文本，容器宽度不足时会在任意位置断行
- **解决方案**：用独立元素（形状+文本框）分别放置标题、数据、说明，或用子卡片布局
- **空行间距**：用 `{ text: "", options: { fontSize: 8 } }` 控制段落间距，比 `lineSpacingMultiple` 更精确

### 母版定义
- **母版 `objects` 中 text 的 options 必须包含 `fontFace`**：否则可能报错
- **母版渐变背景不稳定**：优先用纯色 `{ color: "065A82" }`，渐变容易触发颜色解析错误

## 布局经验

### 卡片式布局（推荐）
- **子卡片比文本混排更可靠**：每个品类/条目用独立的 `roundRect` + `addText`，避免换行问题
- **窄容器内绝不用连续文本混排**：宽度 < 5 英寸时，addText 多行文本必然断句混乱，必须拆成独立元素
- **关键发现/要点列表用卡片**：每条发现一个卡片（标题+数据+说明），不要挤在一个 addText 里
- **标题栏用浅色底+彩色字**：比深色底+白字更柔和，不会产生红绿强对比的视觉冲击
  - 高风险：`fill: "FDE8E8"` + `color: "C0392B"`
  - 健康：`fill: "E8F8E8"` + `color: "27AE60"`
  - 关注：`fill: "FFF3E0"` + `color: "E67E22"`
- **核心指标大号右对齐**：如 `+20.6%` 用 15-16pt 加粗右对齐，下方灰色小字标注"库存增幅"
- **子卡片间距 0.15 英寸**：视觉上紧凑但不粘连

### 数据展示
- **大数字+指标卡+时间轴**三位一体效果最好（参考第10页传统品类设计）
- **季度数据分行显示**：不要把 Q1→Q2→Q3→Q4 挤在一行，用时间轴圆点+连线
- **饼图标签含百分比**：`"轿车 40%"` 而非 `"轿车"`，减少对照图例的认知负担
- **表格图例文字要精简**：不要重复"风险判定标准"等冗余说明

### 章节分隔页
- **编号必须高对比度**：深色背景上用白色，不要用与背景相近的蓝色
- **副标题也要高对比度**：`color: "D0E8F0"` 或更亮，不要用 `8FAFC0` 等与背景接近的色
- **装饰性数字可以更大**：64pt 白色粗体，作为视觉锚点

### 封面页增强
- **装饰圆必须与背景形成强对比**：不要用与背景色接近的圆（如深蓝底+蓝绿圆），改用accent色或更亮的色
- **多圆装饰形成空间纵深**：右上大圆+右下小圆（或左下），不同色阶产生层次感
- **主副标题间加分隔线**：3-4英寸宽的细线，accent色，视觉上分隔标题与信息区
- **信息区多行递进**：时间范围→数据概要→来源说明，字号逐行递减

### 章节分隔页增强
- **右侧加虚线+圆点装饰**：4条长短不一的虚线（dashType:"dash"），每条左端加小圆点
- **虚线长度要有韵律**：如4.0→3.5→4.5→3.0，避免等长单调
- **装饰色与编号色统一**：圆点用accent色，与左侧大号编号呼应

### 框架/目录页
- **三色递进色序**：01用accent、02用midBg、03用deepBg，暗示章节推进
- **编号圆+标题+要点**三层结构，每层字号/字重/颜色严格区分
- **卡片顶部色条**：0.08英寸高的细色条，比整块色头更精致

### 数据对比页（图表+卡片）
- **左侧图表+右侧关键发现卡片**，不要把发现埋在图表下方
- **每个发现一个卡片**：标题(小号灰)+数值(大号彩色)+描述(小号灰)，三层信息
- **卡片左侧色条**：0.08英寸宽竖条，颜色与数据语义对应
- **底部警示条**：用浅黄背景+橙色文字，roundRect圆角

### 风险矩阵页（2×3卡片网格）
- **卡片高度统一**：所有卡片用相同高度，内部元素用固定y坐标而非相对偏移
- **核心指标右对齐**：大号数字+"库存增幅"小标签，y坐标固定保证跨卡片对齐
- **valign:bottom**：大号数字用bottom对齐，确保不同位数数字底部对齐
- **风险色谱**：红(FDE8E8+C0392B)、橙(FFF3E0+E67E22)、绿(C8E6C9+2E7D32)
  - ⚠️ 绿色文字不要用#27AE60（太浅），用#2E7D32（深绿）保证对比度
  - 绿色背景不要用#E8F8E8（太浅），用#C8E6C9（中浅绿）

### 库存风险专题页（图表+风险卡片+时间轴）
- **右侧风险卡片高度要紧凑**：标题→说明→时间轴→分析要点，间距0.15-0.2英寸
- **说明文字紧跟标题**："期末库存比年初增长"放在标题行正下方，不要悬空
- **时间轴Q1-Q4**：连接线+圆点+季度标签(轴上方)+数值(轴下方)+备注
- **峰值标注**：Q3用深色圆点+"▲ 峰值"红色加粗
- **产销率分析**：4条要点，最后一条（主因）用红色加粗突出

### 四策略/四方向页（顶部色块卡片）
- **卡片高度与内容匹配**：4条要点时高度约4.5英寸，不要5.3英寸留大量底白
- **顶部色块高度1.2英寸**：包含图标(28pt)+标题(15pt白色)
- **色块与白底过渡**：色块底部加矩形补丁+白底圆角覆盖，消除色块底圆角
- **条目间距0.7英寸**：比0.85更紧凑

### 产品结构调整页（左右分栏）
- **左红右绿分栏**：收缩/退出用红色系，投入/扩张用绿色系，二元对立一目了然
- **分栏标题条**：0.5英寸高的浅色背景条+彩色标题文字
- **子卡片侧色条**：0.08英寸竖条，颜色与分类语义对应

### 时间轴/路线页
- **连接线加粗(3pt)+箭头终点**：末端加三角形(rotate:90)指示方向
- **节点圆+编号**：0.6英寸直径圆，白色编号文字
- **时间标签在轴上方**，阶段标题在卡片内，不要混在一起
- **"持续"改为"长期"**：与"第1月""第2-3月"格式更统一

### 风险防控页（三级分层卡片）
- **正常/关注/警戒三栏**：绿/橙/红，交通灯隐喻
- **警戒卡片增强视觉权重**：更大的阴影(blur:10,offset:3,opacity:0.15)和略大的高度
- **指标用标签化呈现**：浅色背景roundRect+彩色文字，比纯文字更醒目
- **行动区与指标区分隔线**：0.5pt浅色线

### 结尾页增强
- **装饰圆用accent色**（而非midBg），与深蓝背景形成强对比
- **加第三个小装饰圆**：右下角，midBg色，增加层次
- **主标题48pt**（非44pt），副标题20pt非bold（非22pt bold），层级区分更清晰
- **副标题用浅蓝灰**：C0E0F0，不要用纯白或过亮色

### 结尾页
- **装饰圆不要过大**：缩小至 2-3.5 英寸，避免视觉重心偏移
- **副标题加大加粗**：22pt bold，比 20pt regular 更有收束感
- **来源说明提亮**：`color: "C0D8E8"` 而非 `B0D0E0`

## 对比度规则

### 深色背景上的文字
| 元素 | 推荐色值 | 说明 |
|------|----------|------|
| 主标题 | `FFFFFF` | 纯白，最高对比 |
| 副标题 | `E0F0F8` | 亮蓝白，清晰可读 |
| 说明文字 | `C0D8E8` | 中亮蓝白，投影可辨 |
| 装饰数字 | `FFFFFF` | 不要用与背景接近的色 |
| ❌ 避免 | `8FAFC0`、`B0D0E0` | 与深蓝背景对比不足 |

### 浅色背景上的文字
| 元素 | 推荐色值 | 说明 |
|------|----------|------|
| 正文 | `333333` | 深灰，不用纯黑 |
| 弱化文字 | `888888` | 中灰，投影可辨（不要用 `666666`，太暗） |
| 强调数据 | 主题色 | 红/绿/橙，加粗 |

## 质检经验

### 常见问题清单
1. **换行断裂**：连续文本混排 → 改用子卡片
2. **对比度不足**：深色背景上用低亮度文字 → 提亮
3. **文字层级扁平**：标题/数据/说明挤在一起 → 分层+间距
4. **空间浪费**：卡片内文字只占 30% → 调整卡片高度或增加内容
5. **装饰元素过重**：大圆/粗线抢视觉 → 缩小或弱化
6. **数据格式混乱**：`+20.6%|产销率同比-2.2pp` → 分行或用指标卡

### 质检流程
1. LibreOffice 转 PDF：`soffice --headless --convert-to pdf file.pptx`
2. PDF 转图片：`pdftoppm -jpeg -r 150 file.pdf slide`
3. 逐页视觉检查（用 image 工具）
4. 修复 → 重新生成 → 再次检查，至少一轮无新问题

## 主题适配经验

### 教学场景
- 森林苔藓（forest-moss）绿色系与 Java 生态气质契合
- 代码块用 2 空格缩进（4 空格太宽，PPT 空间有限）

### 数据分析报告
- 海洋渐变（ocean-gradient）深蓝系专业沉稳
- 章节分隔页用深色背景+白色大编号
- 风险矩阵用红/橙/绿三级色谱

### 用户风格偏好
- **强对比优先**：不喜欢"整体较为平淡"，偏好视觉冲击力强的设计
- **信息层级分明**：标题/数据/说明必须视觉分离，不要粘连
- **数据要突出**：核心指标大号加粗，不要淹没在正文中
- **不要小清新**：偏好沉稳专业风，而非柔和淡雅
- **卡片式布局**：比纯文本堆叠更受认可
