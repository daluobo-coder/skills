# OpenClaw Skills

个人开发的 OpenClaw 技能集合。

## Skills

| Skill | 说明 |
|-------|------|
| [pptx-creator](./pptx-creator/) | AI 驱动的专业 PPT 生成，10 套主题、8 种布局、自进化机制 |

## 安装

将 skill 目录复制或软链接到 `~/.openclaw/skills/` 下即可：

```bash
# 软链接方式（推荐，方便更新）
ln -s /path/to/openclaw-skills/pptx-creator ~/.openclaw/skills/pptx-creator

# 或复制
cp -r pptx-creator ~/.openclaw/skills/
```
